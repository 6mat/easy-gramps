# Security

## Reporting a problem

Please **don't** open a public issue for a security problem. Use GitHub's private reporting
instead: the repository's **Security** tab → **Report a vulnerability**. Describe what you found
and how to reproduce it, against the public Gramps Web demo (`https://demo.grampsweb.org`) if you
can, never with real family data.

You can expect an answer within a week. Fixes go into the next release, and the report is
credited unless you'd rather not be named.

## Supported versions

Only the latest release gets security fixes. Easy Gramps passes every read and write to Gramps Web
with the user's own login, so Gramps Web's permissions still apply; problems in Gramps Web itself
belong with the [Gramps Web project](https://github.com/gramps-project/gramps-web-api).
